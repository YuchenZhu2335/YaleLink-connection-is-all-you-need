# Yalelux 设计简报（也是给 Claude Design 的提示词）

> 用法：整段复制给 Claude Design（claude.ai → Design），或交给任何设计师。
> 定稿后的设计规范写在 `docs/design/system.md`，前端 `web/css/tokens.css` 按它实现。

---

## 1. 我们是谁

**Yalelux** 是耶鲁中国学生学者联合会（ACSSY）的志愿者为耶鲁在校生和校友做的开源社群平台。名字呼应耶鲁校训 *Lux et Veritas*（光明与真理）。

- 英文 tagline：**Where Yale's light connects resources and ideas**
- 中文 tagline（请给 2–3 个候选）：例如「耶鲁之光，连接资源与想法」
- 第一期只上线一个功能：**Coffee Chat**（每周约一杯咖啡），以及节点性的大型活动「Coffee Chat 周 / 月」
- 用户：耶鲁中国学生与校友，一半在美国、一半在中国大陆，**手机为主**，大多数从微信群点链接进来
- 语言：中文为主，英文完整可切换；所有界面都要能放下两种语言

## 2. 气质：轻、暖、有人味，和领英拉开距离

- **要**：像朋友约咖啡，不像投简历。克制、干净、有一点温度和光感；让人愿意每周回来点两下
- **不要**：信息流、点赞关注、人脉数、"技能认可"、企业蓝白卡片堆叠；渐变铺底、左边框卡片、emoji 当图标、Inter / Roboto / Arial 当品牌字体
- 关键词：光（lux）、连接、一杯咖啡的距离、校园、真诚

## 3. 品牌与 Logo（请给 3 个方向）

- 字标：**Yalelux**（一个词；可以在字形上区分 Yale 与 lux，但读作一个名字）
- 图形标：围绕"光把两点连起来 / 灯 / 一束光 / 两个人之间的一杯咖啡"等意象，自己发挥
- 必须能：32px favicon 清晰；单色（黑 / 白）可用；放进微信分享卡片和邮件页眉；中英文 tagline 横竖两种组合
- **商标注意**：不使用耶鲁官方盾徽、"Y" 标、Yale 专用字体（Yale typeface），不模仿官方视觉；颜色可以向 Yale Blue（#00356B）致敬，但整体要是独立品牌

## 4. 必须遵守的技术约束（前端是原生 HTML/CSS，要在中国大陆访问）

- **字体只能自托管**：中文用系统字体栈（PingFang SC / Hiragino Sans GB / Microsoft YaHei / Noto Sans CJK SC）；西文可以选 **一款** 开源（OFL）字体由我们自己的服务器提供（如 Google Fonts 上的开源字体），也可以只用系统字体。不要依赖境外 CDN
- 所有颜色、圆角、阴影、间距做成 **design tokens**（CSS 变量），方便直接落地
- 无障碍：正文对比度 ≥ 4.5:1，点击区域 ≥ 44px，颜色区分同时有明暗差（不只靠色相）
- 双端：手机优先（390 宽，底部标签栏）；电脑 1280–1440 宽（顶部导航）
- 图标：线性描边 SVG，统一线宽；不用 emoji

## 5. 要设计的画面

数据全部虚构（中文名如 林可欣、陈思远；邮箱 @example.com；微信号 demo-xxx）。

**品牌页**：3 个 logo 方向（图形标 + 字标，亮 / 暗底，favicon 尺寸）、色板（含语义色）、字体层级、按钮 / 标签 / 输入框 / 卡片样例、中英 tagline 组合。

**手机（390 × 844，可以更高）**

1. **登录**：输入耶鲁邮箱（@yale.edu / @aya.yale.edu）→ 输入 6 位验证码。说明"验证码会发到你的耶鲁邮箱；验证过联系邮箱后也可以发到联系邮箱"
2. **首次填写资料（问卷）**：分步：同意隐私说明 → 联系邮箱（必填，要验证；通知都发这里，国内同学可填常用邮箱）→ 资料。资料题目：
   - 身份：在读 / 校友；在读选阶段（本科 / 硕士 / 博士）和毕业年份；校友填现在的工作和城市
   - 这次想聊什么（多选）：学界求职、业界求职、交朋友、分享经验带学弟学妹
   - 兴趣爱好（1–5 个，可自己加）：徒步、跑步、咖啡、美食探店、摄影、看展、读书、桌游、投资理财、科技 AI……
   - 领域（单选）：金融、咨询、科技互联网、数据与量化、医药生物、学术科研、法律、公共政策、文化传媒、创业、其他
   - 一句话介绍（可选）；联系方式（如微信号，只有匹配成功的人能看到）
3. **约咖啡首页**：本轮信息（"本周 Coffee Chat · 10/5–10/11 · 已有 37 人参加"）；我的状态（选了几个空闲时间）；**为你推荐** 3 张卡片（每张带 1–2 条推荐理由，如"你们都喜欢徒步""一方想聊业界求职，另一方愿意分享经验"）；"不感兴趣"可以划掉；入口：去池子里自己挑
4. **池子（按标签浏览）**：顶部筛选（身份 / 想聊 / 兴趣 / 领域）；人物卡：名字、身份一行（如"硕士 · 2027 届"或"产品经理 · 纽约"）、标签、"3 个共同空闲时间"；按钮状态四种：想认识 / 已邀请 / TA 想认识你（点了直接匹配）/ 已匹配
5. **选空闲时间**：一周 7 天，每天 10:00–21:00，每格 15 分钟、格间隔 20 分钟（每天 19 格）；时间按美东，旁边可显示北京时间；已约定的格子锁定；提前 12 小时截止的格子置灰；底部显示"已选 8 个"+ 保存
6. **收件箱**：「想认识你的人」（附一句留言；按钮：想认识 / 跳过；说明"跳过不会通知对方"）；「我发出的」（等待回复）。每人最多同时 5 个未回复的邀请
7. **匹配成功**：对方联系方式（微信号 + 复制按钮）；你们的共同空闲时间（点一下就约定，对方会收到邮件）；已约定状态；见面后"见到了吗？见到了 / 没见到"
8. **活动页**：「Coffee Chat 月」活动文章（主视觉、日期、主题标签、正文、给微信公众号用的推文文案 + 一键复制、参加按钮）——不登录也能看，方便转发

**电脑（1440 宽，页面型）**

9. **首页（未登录）**：主视觉 + tagline、三步说明（填资料 → 选时间 → 双向确认后交换联系方式）、当前活动、登录按钮
10. **约咖啡（已登录）**：推荐与池子并排，右侧是本轮状态与收件箱摘要
11. **管理后台**：概览数字（注册、完成资料、本轮参与、邀请、匹配、见面）、轮次列表、新建活动轮表单（标题、日期、主题标签、推文正文、发布）、意见箱、邮件发送记录

## 6. 交付

- 品牌页 + 上面 11 个画面（手机 8、电脑 3）
- 一份设计规范：色板（HEX + 用途）、字体（西文字体名 + 中文字体栈 + 字号层级）、圆角 / 阴影 / 间距、组件状态；logo 的 SVG
