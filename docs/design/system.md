## 1. 方向与理由

### 1.1 一句话

晚上在校园里约一个人喝咖啡：纸色是白天的底，海军蓝是夜色里的字，琥珀色是一盏灯。灯只在"这件事是你的，在这里点"的地方亮。

### 1.2 为什么选灯拱

| 方向 | 品牌评审 | 可用性评审 | 工程评审 | 合计 |
|---|---|---|---|---|
| **灯拱 Lantern Arch** | **8** | 7.5 | 6 | **21.5** |
| 活字与日光 Letterpress & Daylight | 6 | **8** | 7 | 21 |
| 两点一光 Two Points, One Spark | 4 | 5.5 | **8** | 17.5 |

选择时按评审的维度加权，不只看合计。

**品牌最难改，组件好改。** Logo、字标和颜色一旦出现在微信群、公众号和邮件里就很难再换；可用性和工程问题都能在组件层修。灯拱在品牌评审里领先最多：商标距离最远（主色与 #00356B 的 ΔE76≈11.9，另两个方向是 6.1 和 7.3），小尺寸 logo 最清楚，tagline 最好。它在另两位评审那里被扣的分几乎都是组件层的问题：选中时段没有边界、截止格的斜纹压住了文字、字号偏小、字体包偏大、圆角写法有 bug、暗色模式不完整。这些本文都已修正（§1.5）。

**活字与日光**的组件细节最好，但它的品牌问题是结构性的：大写衬线 "Yale"、与 Yale Blue 同亮度的海军蓝方块、哥特尖拱，三样放在一起最像官方。它的 logo 也是"拱里有光"，和灯拱是同一个想法，但小尺寸更弱（像眼睛或圆顶）。所以只借用它的组件规则，不用它的品牌形象。

**两点一光**的工程实现最稳，但"点—线—点"正是领英自己表示"人脉"的图形，缩到 16px 只剩一根斜线，整体界面也和领英最接近。所以只借用它的工程做法和"对等"原则，不用它的形象。

### 1.3 品牌原则（每次设计评审都对照检查）

1. **光表示状态，不铺底。** 灯色只用在五个地方：你选的时段、"TA 想认识你"、等你回复的数量、本轮进行中的灯点、当前所在的标签。不做大面积底色、渐变或光晕。
2. **对等。** 匹配页上两人的头像永远一样大。不显示粉丝数、人脉数、浏览量、排名或"热门"。推荐只说明"为什么合拍"，不给"匹配度 92%"这类分数。
3. **以纸色为底，夜色每屏最多一块。** 页面默认用暖纸色；夜色块只留给活动轮、匹配成功这类时刻。这样避免把 lux 读成"奢华"或想到力士（LUX）。灯色是扁平的琥珀色 `#E9A23B`，不用金属金、烫金或金色渐变；衬线只用在字标和大数字上。
4. **不像领英。** 没有信息流、点赞、关注、动态、技能认可。头像是拱形而不是圆形；按钮是 12px 圆角矩形而不是胶囊；卡片是平的细线卡，不叠阴影；主色不是亮蓝。
5. **不像耶鲁官方。** 不用盾徽、"Y" 标、Yale typeface、`#00356B`，也不用海军蓝方块头像。字标全小写，"yale" 不单独出现。所有对外出口都带非官方声明（§8.7）。

### 1.4 从另两个方向借用的内容

- **来自活字与日光：**
  - 每个灯色填充都配一条 ≥3:1 的描边。
  - 待回复用带数字的灯色徽标，不用红点。
  - 人物卡按钮四种状态的明暗阶梯。
  - 中英文分别设行高和字距，中文不加负字距。
  - `.lit` 荧光笔，每屏最多划一处。
  - 拱的含义："两边都朝对方倾，拱才立得住"。
  - 匹配成功时拱线画出来的动画。
  - 头像底色按 id 哈希分配。
- **来自两点一光：**
  - "对等"原则。
  - 夜色（反向）语义 token。
  - 字号用固定 px 加断点，不依赖 clamp。
  - 整站只用一个字体文件的思路。
  - 日期条每天下方用小点表示选了几个时段。
  - 时段图例。
  - 验证码用一个 input 加 `autocomplete="one-time-code"`。
  - 连接动画在减弱动效时直接显示最终状态。
  - 微信圆形裁切时，图形留在 70% 安全区内。
  - 单独手绘一个 16px favicon。

正文要求 4.5:1，≥18.66px 粗体或 ≥24px 的大字要求 3:1，控件边界和图形要求 3:1（WCAG 1.4.11）。

### 2.4 夜色块 `.inverse`

`.inverse` 是一个作用域：它把 `--c-ink`、`--c-primary`、`--c-accent`、`--c-focus` 等变量换成夜色下的值，块里的按钮、链接、焦点环会自动变对，不用再写一套组件。规则如下：

- 只用在两处：**活动轮横幅**（Coffee Chat 周 / 月期间）和**匹配成功页头**。toast 也用 `.inverse` 着色，但它是浮层，不计入"每屏一个"。
- 整块是平涂，没有渐变。四角 `--radius-xl` 24px。
- 块里的数字用 `--c-accent-text`（`#F2B457`）；灯色按钮的字用 `--c-accent-ink`（夜色）。
- 焦点环在块里自动变成奶白。

### 2.5 用色规则

1. **灯色只做填充。** `--c-accent` 不能用作浅底上的文字、细线、图标描边或输入框边框（在纸上只有 1.92:1）。需要琥珀色的字时用 `--c-accent-text`。
2. **浅底上的每个灯色填充都配 1px `--c-accent-edge` 描边，字用 `--c-accent-ink`。** 包括已选时段、"TA 想认识你"按钮、待回复徽标和灯点。暗色模式和夜色块里，描边与填充同色（看起来就是没有描边）。
3. **灯色只表示"亮着"，不表示"小心"。** 警告用铁锈色 `#A2480F`，并始终带三角图标和文字。琥珀色的字 `#85570A` 和警告色的亮度比只有 1.03:1，单靠颜色分不出来。
4. **语义色从不单独出现**，一定配图标和文字（成功：勾；警告：三角；错误：圆形叹号）。
5. **主色与耶鲁蓝的关系**（商标说明里用这一句）：主色 `#1E3A5F` 与 Yale Blue `#00356B` 色相接近（214° 对 210°），但饱和度低得多（HSL 52% 对 100%），更灰，感知色差 ΔE76≈11.9。品牌位置一律不使用 `#00356B`。
6. **不出现**：渐变底、金属金、霓虹色，卡片左侧的彩色竖条，纯灰色（`#808080` 一类）的阴影。
7. **建议加的检查**：在 `scripts/check-architecture.mjs` 里增加一条规则，在 `.inverse` 作用域和暗色媒体查询之外，如果出现 `color: var(--c-accent)` 或 `border-color: var(--c-accent)` 就报错。

## 3. 字体

### 3.1 西文：Newsreader（只用一个家族）

- **字体**：Newsreader（Production Type，SIL Open Font License 1.1），从 npm 包 `@fontsource/newsreader` 5.3.0 取文件。这个包只在开发时下载一次；文件提交到 `web/assets/fonts/`，自己的服务器提供，不走任何 CDN，`web/` 也不因此多出运行时依赖。
- **为什么选它**：
  - 它是为屏幕设计的温和过渡体衬线，和 Yale typeface 那种 Jenson 风格的旧式衬线差别很大。
  - 静态文件的数字默认就是**等宽、齐线**的（10 个数字宽度相同），还带 `tnum` 特性，适合时段表、"已选 8 个"、验证码和后台数字。实测 Fraunces 的 Google 构建版没有 tnum，Manrope 的可变字体默认字重是 200，这两款都被排除。
- **只发一个字重**：500。
  - `web/assets/fonts/newsreader-latin-500-normal.woff2`：从 `files/newsreader-latin-500-normal.woff2`（23.6 KB）按下面的 unicode-range 再子集化后是 **20.7 KB**。
  - `web/assets/fonts/newsreader-italic-lux.woff2`：从 `files/newsreader-latin-500-italic.woff2` 只保留 `l u x` 三个字形，**1.1 KB**，只给字标的活字备用。网页上的字标是 SVG，所以中文用户基本不会下载这个文件。
  - 合计约 22 KB。两个都是静态实例，不依赖可变字体，在旧版 X5 / TBS 内核上也不会退回到细体。
  - 全站不使用 Newsreader 的其他字重。在所有用到衬线的地方写 `font-synthesis: none`，禁止浏览器合成假粗体或假斜体。
- **unicode-range**：`U+0020-007E, U+00A0-00B6, U+00B8-00FF, U+0131, U+0152-0153, U+2013, U+20AC, U+2122`。这里刻意排除了 `· — ‘ ’ “ ” …`（U+00B7、U+2014、U+2018–201D、U+2026），让这些中文标点始终由中文字体以全角显示。
- **生成命令**见附录 A。需要做样稿时可以临时用 `https://fonts.googleapis.com/css2?family=Newsreader:ital,wght@0,500;1,500&display=swap`，但**网站上禁止使用这个链接**。

### 3.2 正文和中文：系统字体栈

```css
--font-body: -apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Hiragino Sans GB",
             "Microsoft YaHei", "Noto Sans CJK SC", "Noto Sans SC", "Source Han Sans SC",
             "Helvetica Neue", sans-serif;
```

- 苹果设备：拉丁字母用 SF，中文用苹方。Windows：拉丁字母用 Segoe UI，中文自动落到微软雅黑。安卓：Noto Sans CJK。
- 不写 `system-ui`：Windows 的非中文系统区域设置下，它可能选出日文字形。
- 中英文正文、中文标题、按钮、chip、输入框、人名一律用这个字体栈。

### 3.3 衬线可以用在哪里（白名单）

| 用 Newsreader | 不用 |
|---|---|
| 字标（正式用 SVG，活字只是备用） | 中文标题、中文正文 |
| 单独成行或成块的大数字，≥20px：本轮"37 人"的 37、"已选 8 个"的 8、后台统计、"三步说明"的 1 2 3 | 句子里的数字（"3 个共同空闲时间"，就用正文字体） |

### 3.5 排版规则

- `body { line-break: strict; word-break: normal; overflow-wrap: break-word; }`。不要用 `overflow-wrap: anywhere`：它会把 flex 行里的最小内容宽度压到一个字符，按钮文字会被拆开。长的邮箱和微信号所在的元素单独加 `word-break: break-all`。
- 中文在任何字号下字距都是 0，不加负字距。英文的大标题可以用 −0.01em，字标用 −0.015em。
- 全大写只用于英文眉题；中文没有大小写。
- 所有数字列（时段、统计、计数、表格）都写 `font-variant-numeric: tabular-nums`。系统字体回退时也能保持对齐。
- 中英文混排时英文两侧不手动加空格。支持 `text-autospace: normal` 的浏览器会自动处理，不支持的就算了。文案里的写法是"本周 Coffee Chat"，空格由文案本身带。
- 英文模式下行高：正文 1.6，长文 1.65。
- 段落宽度：中文 ≤34em，英文 ≤66ch。

### 4.1 圆角

| Token | 值 | 用在 |
|---|---|---|
| `--radius-xs` | 6px | 小徽标、键盘提示 |
| `--radius-s` | 10px | 时段格、验证码格 |
| `--radius` | 12px | 按钮、输入框、提示条、分段控件、问卷选项卡片、图标按钮 |
| `--radius-l` | 16px | 卡片、人物卡、桌面弹窗 |
| `--radius-xl` | 24px | 底部弹层的两个上角、夜色块、首页主视觉 |
| `--radius-pill` | 999px | 标签、筛选 chip、计数徽标、灯点 |
| `--radius-arch-s` | `18px 18px 8px 8px` | 36×42 头像（顶栏） |
| `--radius-arch-m` | `28px 28px 10px 10px` | 56×64 头像（人物卡） |
| `--radius-arch-l` | `36px 36px 12px 12px` | 72×84 头像（匹配页头） |

- **拱形**是 logo 的拱在界面里的重复：上面是半圆，下面是小圆角。只用在头像和插图框上。
- **不要写成 `999px 999px 12px 12px`**：浏览器会把所有半径按同一比例缩小，56×64 的头像底角会变成 0.34px，看起来是直角；宽的封面图会被裁成圆顶。每个尺寸都写死半径，并满足两个条件：上面两个半径之和等于宽度；上半径加下半径不超过高度。
- 按钮用 12px 圆角矩形，不用胶囊，以区别于领英。chip 和标签用胶囊，因为它们是"小物件"。

### 4.2 描边

- 装饰细线：`1px solid var(--c-line)`，用在卡片边框、分隔线、标签栏上沿和顶栏下沿。
- 控件边界：`1.5px solid var(--c-line-strong)`，用在输入框、次要按钮、未选 chip 和可选时段。
- 强调：选中和焦点用 2px。
- 灯色填充：`1px solid var(--c-accent-edge)`。
- 虚线：`1.5px dashed var(--c-line-strong)`，只用于"已邀请"（等待中）和"+ 自定义"标签两处。
- **任何卡片都不加左侧彩色竖条。**

### 4.3 阴影

阴影用墨蓝色调，不用中性灰。**卡片默认没有阴影**，平放在纸上，只靠细线边框区分。

## 5. 组件

### 5.0 通用规则

- **焦点**：所有可交互元素在 `:focus-visible` 时显示 `outline: 2px solid var(--c-focus); outline-offset: 2px; box-shadow: var(--focus-ring);`。
  - 焦点环外偏 2px，所以画在底色上，即使元素本身是海军蓝填充也看得见。
  - 在 `.inverse` 里焦点环自动变成奶白。
  - 灯色光晕**只用于焦点**；"亮着"的元素不加光晕。
- **点击区**：视觉上小于 44px 的元素（chip、标签栏图标、关闭按钮）用伪元素扩大点击区：

  ```css
  .chip { position: relative; }
  .chip::after { content: ""; position: absolute; top: -2px; bottom: -2px; left: 0; right: 0; }
  ```

  不用 `inset` 简写（Chrome 87 / Safari 14.1 以下的老微信内核不支持），也不能靠 margin（margin 不算点击区）。相邻 chip 之间留 ≥8px，扩大后的点击区不会重叠。
- **悬停**：所有 `:hover` 写在 `@media (hover: hover) { … }` 里，避免触屏点过之后留下半亮的状态。
- **按下**：`:active` 的样式是按钮下沉 1px（`translateY(1px)`），配 `--dur`。iOS 需要在 document 上加一个空的 passive 监听才会触发：`document.addEventListener("touchstart", () => {}, { passive: true })`。
- **禁用**：
  - 真正不可用、也不需要解释的，用 `disabled`。
  - 需要解释原因的（已达上限、已约定、已截止），用 `aria-disabled="true"`，保留焦点，用 `aria-describedby` 说明原因，点击时弹 toast 或气泡说明。
- **加载**：按钮加 `aria-busy="true"`，锁定当前宽度，文字变透明，中间放一个 18px 的旋转圈（2px 描边，用 currentColor，0.8s 匀速）。减弱动效时改成显示"处理中…"文字。用 `YL.ui.busy(btn, true)` 切换。

## 8. Logo

### 8.1 三个方案（第一个是推荐方案）

| 方案 | 含义 | 优点 | 风险 | 结论 |
|---|---|---|---|---|
| **① 灯拱 Lantern Arch**（推荐） | 一道圆拱，圆心处一盏灯 | 两个基本形状，16px 仍能看出"拱 + 点"；离官方视觉最远；和"窗户一扇扇亮起"的时段表是同一个意象 | 单色 16px 可能像磁铁或挂锁 | 定稿，等识别测试 |

### 8.2 定稿图形标：几何与含义

**几何**（viewBox 0 0 64 64）：

- 一条描边路径：圆心 (32, 30)、半径 17 的半圆，两侧各接 20 单位长的立柱；描边宽 7，圆头端点。
- 一个同心圆：半径 8.5。圆与拱内侧之间的间隙四周一致，都是 5 单位。32px 时约为 3.5px 的线加 2.5px 的缝，16px 时仍能分开。
- 外框 x 11.5–52.5，y 9.5–53.5，视觉上居中。
- 没有 Y 形、盾形或冠饰。

**含义**（对外统一这样说）：

> 一道拱，只有两边都朝对方倾，才立得住——就像 Coffee Chat 里，两个人都点了"想认识"才算匹配。灯在拱的圆心，拱上每一点到它都一样远：光属于两边，不偏向谁。

（旧说法"灯在拱顶石"与几何不符，"两根立柱是两个人"也太牵强，两种都不再使用。）

### 8.3 字标

- **写法**：小写 `yalelux`，一个词，中间不加空格。`yale` 用 Newsreader 500 正体，`lux` 用 Newsreader 500 斜体，**同色、同字重、同一条基线**。斜体的 `lux` 是"倾身进来的光"。两段靠字形而不是颜色区分，所以单色也成立。
- **为什么小写**：和耶鲁官方的大小写混排衬线字标 "Yale" 明显不同，语气也更像朋友约咖啡。正文里提到名字时仍写作 "Yalelux"。
- **颜色**：浅底上用 `--c-ink` `#1B2638`；深底上用 `#F3EBDD`。不分色，**永远不用 `#00356B`**。
- **字距**：−0.015em；正体 e 和斜体 l 的接缝处再收 10/1000 em。
- **实测**：从 18px 起，`lux` 的斜体（u、x 的形状变化最明显）就能分辨；导航用的 22px、邮件用的 24–28px 都没问题。
- **正式使用的是描边 SVG**：`web/assets/brand/wordmark.svg`，由字体轮廓生成（附录 A），约 4 KB，`fill="currentColor"`。logo 不依赖字体是否加载完成。
- **活字备用**（SVG 加载不了时，或在需要可选中文本的地方）：

  ```html
  <span class="wordmark">yale<i>lux</i></span>
  ```

  ```css
  .wordmark {
    font-family: var(--font-serif);
    font-weight: 500;
    font-size: 22px;                 /* 按场合改 */
    letter-spacing: var(--tracking-wordmark);   /* -0.015em */
    line-height: 1;
    color: var(--c-ink);             /* 不分色 */
    font-synthesis: none;
    font-kerning: normal;
    white-space: nowrap;
  }
  .wordmark i { font-style: italic; margin-left: -0.01em; }
  ```

  斜体字体文件只有 `l u x` 三个字形，所以 `.wordmark i` 里只能放这三个字母。

### 8.5 使用规范

- **安全距离**：四周留出 D，D = 灯的直径 = 图形标高度的 17/64（约 0.27 倍）。组合使用时，以组合里图形标的 D 为准。
- **最小尺寸**：
  - 单独的图形标：屏幕上 20px；印刷 6mm。
  - 方块：24px 及以上用 `tile.svg`；16px 用 `favicon-16.svg`。
  - 字标：字号 16px（SVG 高 16px）。
  - 横排组合：字标 18px。
- **颜色版本**：
  - 浅底（纸色、白）：拱 `#1E3A5F`，灯 `#E9A23B`。
  - 深底（夜色、暗色模式）：拱 `#F3EBDD`，灯 `#F2B457`。
  - 单色：全部 `currentColor`。拱和灯之间的缝让单色版仍能看清。
  - 琥珀底上：只能用墨色单色版。
  - 照片或复杂背景上：只能用方块。
- **禁止**：
  - 加渐变、外发光、投影，或在 logo 本身外面加光晕。（唯一例外：夜色大幅装饰画面上，灯的后面允许一圈半径 14、18% 透明度的 `#F2B457` 圆。）
  - 把灯换成其他颜色；把灯色放在琥珀底上。
  - 旋转、拉伸，或把拱改成实心。
  - 外面套圆环或盾形（会像校徽）；加 "Y"。
  - 用海军蓝方块当头像。
  - 字标改用其他字体；`Yale` 大写，或单独换色、换字重。
  - 使用 `#00356B`。
  - 把 logo 放在图案或照片上而不用方块。

## 10. 文案语气

### 10.1 原则

1. **像学长学姐跟你说话**：用"你"，不用"您"；不叫"亲"，不说"同学们"。
2. **说清楚会发生什么**：每个按钮都要说明后果（"跳过不会通知对方"、"对方会收到邮件"）。
3. **具体**：写"3 个共同空闲时间"、"满 20 人开放推荐"，不写"更多精彩"。
4. **不催、不制造焦虑**：不写"你已经 3 天没来了"、"名额有限"、"错过就没了"。
5. **不用职场黑话**：不说人脉、资源对接、赋能、拓展圈子、高效社交；说认识、聊聊、喝杯咖啡。
6. **克制标点**：不用感叹号，不用 emoji，不用"~"。句号可以省略的地方就省略（按钮、标签）。
7. **按钮用动词**，2–6 个字："想认识"、"选空闲时间"、"约这个时间"。
8. **英文**：句首大写（sentence case），说法直接（"Say hi"、"Skip"），不用 "Connect" 和 "Network"。

## 附录 A：生成字体和字标

在仓库外的临时目录里做，只把生成的文件提交进 `web/assets/`。需要 Python 和 `pip install fonttools brotli`。

```bash
npm pack @fontsource/newsreader@5.3.0 && tar xzf fontsource-newsreader-5.3.0.tgz
# 正体 500：按本站 unicode-range 子集化（约 20.7 KB），保留 kern / liga / tnum / pnum
pyftsubset package/files/newsreader-latin-500-normal.woff2 \
  --unicodes="U+0020-007E,U+00A0-00B6,U+00B8-00FF,U+0131,U+0152-0153,U+2013,U+20AC,U+2122" \
  --layout-features="kern,liga,tnum,pnum" --flavor=woff2 \
  --output-file=web/assets/fonts/newsreader-latin-500-normal.woff2
# 斜体 500：只留 l u x（约 1.1 KB）
pyftsubset package/files/newsreader-latin-500-italic.woff2 \

cp package/LICENSE web/assets/fonts/OFL-Newsreader.txt   # 随字体附上许可证
```

字标描边 SVG（`web/assets/brand/wordmark.svg`）：

```python
from fontTools.ttLib import TTFont
from fontTools.pens.svgPathPen import SVGPathPen
from fontTools.pens.transformPen import TransformPen
R = TTFont("package/files/newsreader-latin-500-normal.woff2")
I = TTFont("package/files/newsreader-latin-500-italic.woff2")
upm = R["head"].unitsPerEm                       # 2000
def run(font, text, x, track):
    gs, cmap, hm, out = font.getGlyphSet(), font.getBestCmap(), font["hmtx"], []
    for ch in text:
        g = cmap[ord(ch)]
        pen = SVGPathPen(gs, lambda v: f"{round(v)}")
        gs[g].draw(TransformPen(pen, (1, 0, 0, -1, x, 0)))
        out.append(pen.getCommands()); x += hm[g][0] + track
    return out, x
track = round(-0.015 * upm)
a, x = run(R, "yale", 0, track)
b, x = run(I, "lux", x - 0.01 * upm, track)      # 接缝处再收 0.01em
svg = (f'<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 {-int(upm*.78)} {round(x)} {int(upm*1.02)}" '
       f'role="img" aria-label="Yalelux"><path fill="currentColor" d="{" ".join(a+b)}"/></svg>')
open("web/assets/brand/wordmark.svg", "w").write(svg)   # 约 4 KB；viewBox 里基线在 0.78 处
```
