- [x] 登录（域名白名单 + 演示码 + 资料，含学联身份）

## v0.2 真实后端

- **先上 Coffee Chat 内测**（RFC 0001）：Node.js 22 + Hono + PostgreSQL、邮箱验证码登录、邮件通知；预计 15–21 人日
- 存量模块按 coffee 的样子迁到 `YL.api`（`LEGACY_STORE_MODULES` 名单清零）

- 邮箱验证码登录（服务端白名单）、会话
- Postgres + 对象存储；`store.js` / `auth.js` 切换到 API
- 学联身份申请与审核；权限矩阵落地
- 评论、站内通知（任务分配、逾期、活动提醒、志愿者确认）
- 内容审核与举报
- 数据导入：从现有微信群 / 表格批量导入活动与联系人（脱敏）

## v0.3 国内可用

- 静态资源部署到 COS / OSS + CDN；后端部署国内云；ICP 备案
- 微信登录绑定（邮箱验证仍是第一层）；微信模板消息推送活动与任务
- 微信小程序壳（活动报名、志愿者、任务反馈三个高频场景）
- Gitee 镜像同步

## v0.4 社区治理

- 贡献值体系正式化（发帖、帮助、组织活动、维护 SOP）
- 版主 / 社群管理员机制
- SOP 与模板"市场"：跨校友会复用
- 年度数据回顾（活动数、志愿者时长、内推成功数）
